Stay Kit

Make a hotel website in minutes. You give it the hotel's details and photos, and it gives you a finished website in English and Amharic. You run one command, then click buttons in your browser.

1Start it

Open the terminal in the stay-kit folder and type this. Leave the terminal open while you work.

npm run dev

2Open it in Chrome

Go to localhost:3000/admin.

First time only: you will see “Create your admin account”. Type any email and a password (8+ letters). That becomes your login.

3Add a hotel

On the Clients page, click Import from folder to bring in hotels that already exist, or click + New client and fill in the hotel name and the owner's email.

4Fill in the hotel

Click Edit on the hotel's row. Change the words, phone number, rooms and prices, upload the photos, then click Save changes.

The WhatsApp number is numbers only, with the country code and no plus sign. Example: 251911234567.

5Pick a design

Click the ⋯ button on the hotel's row, then Preview all designs. Use the arrow keys (or swipe on a phone) to flip through all 15 designs. When the client chooses one, open Edit → Look & hero, pick it in the Style box and save.

6Look at the real website

Click View on the hotel's row.

7Give it to the client

Click ⋯, then Download website (zip). Wait about a minute. Send the zip to the client; they upload what is inside it to their hosting (on cheap hosting, the public_html folder).

Done.

If something goes wrong

The page is stuck or keeps flickering

Press Ctrl + C in the terminal, then type:

rm -rf .next && npm run dev
“Port 3000 already in use”

Type this, then run npm run dev again:

pkill -f "next dev"
“Too many attempts” when logging in

Wait 10 minutes.

Download shows a red message

Read it. It says what to fix, for example a missing field in the hotel's details.

I forgot my password

Type this, with your own email and a new password:

ADMIN_EMAIL=you@example.com ADMIN_PASSWORD=new-password npm run seed

Optional commands (the buttons above do the same things): npm run demo, npm run themes -- demo-lodge, npm run try -- hotel-name, npm run make -- hotel-name, npm run test. Developer details: TECHNICAL.md.
